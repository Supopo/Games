# NewGames Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a standalone modern Android Compose application named `NewGames` that reproduces the existing `Games` visual style and non-advertising game flows.

**Architecture:** Use one Compose activity, Navigation Compose routes, screen-scoped ViewModels with StateFlow, and small repositories for bundled assets. Keep `NewGames` independent from the legacy `Games` and `LibMVVM` modules.

**Tech Stack:** Kotlin 2.2.21, AGP 8.13.2, Gradle 8.13, Jetpack Compose Material 3, Compose BOM 2025.08.00, Navigation Compose, Lifecycle ViewModel, Kotlin Coroutines, AndroidX tests.

**Spec:** `docs/superpowers/specs/2026-09-16-newgames-design.md`

## Global Constraints

- Do not modify the existing `Games` or `LibMVVM` source files.
- Do not include advertising, analytics, update-check, Pangle, or Pgyer dependencies, permissions, providers, or metadata.
- Preserve the legacy palette, gradient background, rounded colorful entry cards, and Chinese labels.
- Use Compose for all new UI; no DataBinding, ButterKnife, RxJava 2, old Support Library, or legacy MVVM dependency.
- New application id is `com.xxx.newgames` and project directory is `NewGames`.
